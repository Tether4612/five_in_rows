# 🎮 5 в ряд (вариация Connect Four)

Простая игра **«5 в ряд»** — вариация классической Connect Four — на Python с использованием библиотеки **Tkinter**. Два игрока по очереди бросают фишки в сетку 6×7, цель — собрать **пять фишек в ряд** по горизонтали, вертикали или диагонали.

## ✨ Возможности

- 🎯 Игровое поле **6 × 7** (строки × столбцы)
- 🔴 Два игрока: **красные** и **жёлтые** фишки
- 🏆 Условие победы — **5 фишек в ряд** (горизонталь, вертикаль, диагональ)
- 🎬 Плавная анимация падения фишек (с ускорением под действием «гравитации»)
- ✨ Анимация победной линии с миганием
- 🤝 Определение ничьей (когда всё поле заполнено)
- 🔄 Кнопка **«Новая игра»** для перезапуска
- 📊 Индикатор текущего хода

---

## 🕹️ Как играть

1. При запуске игры первым ходит **игрок 1 (красные)**.
2. **Кликните левой кнопкой мыши** по любому столбцу — фишка упадёт в самую нижнюю свободную ячейку этого столбца.
3. Ходы передаются по очереди: **красные → жёлтые → красные → …**
4. Побеждает тот, кто первым соберёт **5 фишек в ряд** (по горизонтали, вертикали или диагонали).
5. Если поле полностью заполнено, а победителя нет — объявляется **ничья**.
6. Для перезапуска нажмите кнопку **«Новая игра»**.

## 🔧 Основные функции

| Функция | Назначение |
|---|---|
| `new_game()` | Инициализация новой игры, очистка поля |
| `draw_board()` | Отрисовка игрового поля и всех фишек |
| `draw_piece(r, c, player)` | Отрисовка отдельной фишки |
| `on_click(event)` | Обработка клика мыши по полю |
| `drop_piece(col, row)` | Логика «падения» фишки в столбец |
| `animate_drop(...)` | Анимация падения фишки с ускорением |
| `after_move(r, c)` | Проверка победы / ничьей после хода |
| `find_winner_line(r, c)` | Поиск линии из 5 одинаковых фишек |
| `animate_win(cells)` | Анимация отрисовки победной линии |
| `blink_line(line, count)` | Мигание победной линии |
| `switch_player()` | Передача хода другому игроку |
| `is_draw()` | Проверка на ничью |

## 🎨 Настройки

Все ключевые параметры вынесены в константы в начале файла — их можно легко изменить:

```python
ROWS = 6            # Количество строк
COLUMN = 7          # Количество столбцов
CELL_SIZE = 80      # Размер ячейки в пикселях
RADIUS = 30         # Радиус фишки
WIN_LENGTH = 5      # Длина выигрышной линии

PLAYER1 = '#E53935'          # Цвет игрока 1 (красный)
PLAYER2 = '#FDD835'          # Цвет игрока 2 (жёлтый)
BACKGROUND_COLOR = '#1565C0' # Цвет фона поля
VOID_COLOR = '#ffffff'       # Цвет пустых ячеек
```

Например, чтобы играть в классический **Connect Four (4 в ряд)**, измените:
```python
WIN_LENGTH = 4
```

А чтобы увеличить поле:
```python
ROWS = 8
COLUMN = 9
```

## 📌 Известные особенности

- Столбец определяется по координате `X` клика — клик в любом месте столбца работает корректно.
- Во время анимации падения фишки новые клики блокируются (`cliked = True`).
- Победа определяется только по линии из `WIN_LENGTH` фишек текущего игрока.
